三问学习机

鸿蒙端 + AI 中间层

学完就忘，往往是因为只答了「是什么」。这个鸿蒙 App 要求你把一个知识点答三遍——是什么、为什么、怎么用，再由 AI 逐问打分、追问。

独立开发（端 + 中间层）
ArkTS · ArkUI · FastAPI
DeepSeek · SSE · Docker
three-question-study-machine

端侧
探索、课程、作答、评价、复习、学习报告六页全在 ArkTS / ArkUI 实现，记录落本地 RelationalStore。
提示词
FastAPI 把 DeepSeek 封装成 4 个接口，三问各配一套评分标准，不让三个问题共用一把尺。

爱宠 App

安卓端 · 一站式宠物服务

养宠的人真正会打开的是一个 App：买东西、问症状、找门店。我把这几件事，加上一套离线的风险识别，收进同一个端里。

2025.09 – 2025.12
核心开发（AI 能力主导）
Java · Kotlin · SQLite
OkHttp · qwen-turbo · 百度语音
love-pet-android

对话
OkHttp 封装 DashScope 兼容接口，维护最近 20 条上下文，子线程请求、主线程回调，回答回来时不卡界面。
自查
按宠物类型、年龄段、症状做加权分诊，输出 7 类可能疾病、概率排序与就诊科室——这块是规则引擎，不是大模型，离线也零成本。
兜底
危险食物识别用内置清单 + 关键词匹配，没网也能拦住巧克力、洋葱、葡萄、木糖醇。
存储
SQLiteOpenHelper 建六张表，存用户资料、收藏与浏览记录，不依赖云端。
实测在本机模拟器构建安装（compileSdk 32 / minSdk 21），跑通首页、医疗、自查结果三条主链路；自查给出「轻症」分级与 7 条带概率和科室的建议。

宠物知识库 RAG + Agent

后端 · 让回答有出处

模型其实不知道猫能不能吃巧克力。我给它一本喂养手册，要求它只按手册回答；答不出来就说不知道，而不是编一句。

2025.10 – 2026.01
独立开发
FastAPI · LangChain · Chroma
FastEmbed · LangGraph
pet-feeding-rag
pet-feeding-agent

检索
RecursiveCharacterTextSplitter 按 500 字一块、50 字重叠切开，bge-small-zh-v1.5 本地 Embedding（ONNX，免 Key），Chroma 落盘，余弦距离 top-4 召回。
可核验
召回片段进 Prompt 的同时，把 sources（原文 + 距离）一起返回，答案对不对可以当场翻手册核对。
智能体
LangGraph ReAct，三个工具——知识库检索、AST 安全计算器、联网搜索——由模型自己挑，可多轮调用；计算器走白名单解析，不用 eval。
降级
没配 Key 或调用失败时自动退回纯检索模式，接口不报错、链路不断。
实测召回 4 条片段，余弦距离 0.4568 – 0.4909（越小越相关），全部来自 pet_feeding_manual.md；Agent 侧实测三个工具均被模型自主调用。
